# Contributing

Help builders find Microduck accessories, hardware modifications and useful work inside replica projects. Contributions can add a project, correct a description or document a new milestone.

## Suggest a project

Open an issue or pull request with:

- The project name, author and original public URL.
- The most relevant category and the specific accessory or modification.
- A short explanation of what it does and who can use it.
- Links to available designs, printable files, circuits, code or instructions.
- Hardware compatibility and the current evidence: design, simulation, board test or physical robot demonstration.

Design-stage work is welcome when its status is clear. A render is not a photograph of a finished part; a real controller driving a simulator is not a completed physical robot.

## Write an entry

Use the project's original name and a short, factual paragraph. Lead with what it changes or enables, then describe the useful materials and the key validation boundary. Avoid promotional claims and unsupported performance comparisons.

```markdown
- **[Project name](original URL)** (author) — What the modification does. Available materials, relevant hardware and current progress.
```

Keep English and Chinese entries aligned when possible. If you can only contribute one language, say so in the pull request.

## Credit and scope

Link to the author's maintained source. For a fork, identify its substantive changes and credit the upstream project; an unchanged copy does not need a separate entry. A full robot build is relevant when it contains a specific part, hardware adaptation or reusable implementation.

Authors may submit their own work. Disclose authorship, collaboration, sponsorship or a purchasing relationship. Inclusion does not imply endorsement or universal compatibility.

Do not upload someone else's photographs, CAD, code or other assets without the rights required by their license. Public availability does not automatically grant permission to redistribute. Link to the original material when in doubt.
